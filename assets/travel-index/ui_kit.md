# 13. THE VAGARY INDEX UI KIT (FULL COMPONENT LIBRARY)
# Complete, structured, build-ready design system for all components.

## Component Categories

1. GLOBAL COMPONENTS (Premium + Futuristic)
2. TRAVELER IDENTITY COMPONENTS (Premium + Cultural)
3. GUIDE INTELLIGENCE COMPONENTS (Futuristic + Cultural + Adventure)
4. JOURNEY-PHASE COMPONENTS (Futuristic + Premium)
5. PERSONA EVOLUTION COMPONENTS (Premium + Cultural + Futuristic)
6. UTILITY + MOTION COMPONENTS (Premium + Futuristic)

## 1. GLOBAL COMPONENTS

### 1.1 Global Navigation Bar
- Elements: Globe icon (home), Regions, Countries, Cultural Stories, My Journey, Profile
- Behavior: Smooth fade transitions, gold accent hover, region glyph animations
- Amplitude behavior: Show traveler's current persona in Profile if logged in

### 1.2 Global Map
- Elements: Rotating globe, region glyphs, seasonal overlays, cultural hotspots, amplitude-matched destination markers
- Behavior: Physics-based rotation, hover reveals cultural cards, amplitude-matched glow pulses

### 1.3 Search & Intelligence Bar
- Elements: Smart search, predictive suggestions, amplitude-matched recommendations
- Behavior: Typing reveals intelligent predictions, cultural glyphs appear for cultural queries

### 1.4 Global Footer
- Elements: Brand narrative, cultural mission, travel intelligence statement
- Behavior: Subtle gold shimmer on scroll end

## 2. TRAVELER IDENTITY COMPONENTS

### 2.1 Amplitude Sliders
- Sliders: pace, cultural curiosity, adventure appetite, comfort vs exploration, food openness, social openness, planning vs spontaneity, travel confidence
- Behavior: Gold or cyan amplitude bars, micro-pulse animation when adjusted

### 2.2 Identity Cards
- Elements: Traveler name, amplitude vector, persona type, strengths, curiosities
- Behavior: Amplitude bars animate on load, persona glyph pulses subtly

### 2.3 Onboarding Question Cards
- Elements: Micro-questions, cultural prompts, adventure prompts
- Behavior: Fade-in storytelling tone, serif typography for cultural questions

## 3. GUIDE INTELLIGENCE COMPONENTS

### 3.1 Guide Header
- Elements: Country name, region glyph, seasonal indicator, amplitude match score, journey phase indicator
- Behavior: Gold pulse on amplitude match, seasonal icon animates subtly

### 3.2 Cultural Briefing Module
- Elements: Cultural glyph, adaptive briefing text, depth meter
- Behavior: Depth meter expands based on amplitude, serif typography for narrative

### 3.3 Safety & Norms Module
- Elements: Etiquette cards, "Do / Avoid" list, social norms intensity meter
- Behavior: Intensity meter animates based on risk tolerance

### 3.4 Exploration Route Cards
- Types: Urban routes, nature routes, cultural routes, food routes
- Elements: Map preview, route difficulty, pace indicator, amplitude match tags
- Behavior: Route lines animate on hover, amplitude match glows cyan or gold

### 3.5 Food Intelligence Cards
- Elements: Recommended dishes, sensory intensity meter, food openness meter, neighborhood clusters
- Behavior: Sensory meter pulses, food clusters animate outward

### 3.6 Neighborhood Intelligence Cards
- Elements: Neighborhood name, pace indicator, exploration radius, cultural highlights
- Behavior: Radius expands based on amplitude, cultural highlights fade in

### 3.7 Packing Guidance Cards
- Elements: Climate, season, cultural formality, environmental sensitivity, amplitude-matched items
- Behavior: Items reorder based on amplitude

### 3.8 "What to Expect" Module
- Elements: Landing experience, cultural rhythm, environmental conditions, pace of life
- Behavior: Predictive icons animate, rhythm meter pulses

### 3.9 Bundle Recommendation Cards
- Types: Region bundle, climate bundle, amplitude bundle, seasonal bundle
- Behavior: Amplitude bundle highlights traveler identity, region bundle uses region glyph

## 4. JOURNEY-PHASE COMPONENTS

### 4.1 Pre-Travel Dashboard
- Elements: Cultural briefing, packing list, expectations, safety notes, route previews
- Behavior: Calm, premium transitions

### 4.2 In-Transit Dashboard
- Elements: Landing guidance, airport → city transitions, quick cultural cards, micro-briefings, offline mode
- Behavior: Lightweight, fast animations, predictive countdown

### 4.3 On-Location Dashboard
- Elements: Neighborhood intelligence, food clusters, etiquette guidance, exploration routes, cultural depth modules
- Behavior: Map interactions, amplitude-matched highlights

### 4.4 Post-Travel Dashboard
- Elements: Reflection prompts, memory cards, persona evolution, next-destination intelligence
- Behavior: Soft, reflective transitions

## 5. PERSONA EVOLUTION COMPONENTS

### 5.1 Persona Card
- Elements: Persona type, amplitude vector, strengths, curiosities, exploration style
- Behavior: Amplitude bars animate, persona glyph pulses

### 5.2 Evolution Timeline
- Elements: Amplitude changes, persona shifts, cultural depth gained, exploration patterns
- Behavior: Timeline scroll reveals evolution

### 5.3 Global Progress Map
- Elements: Regions visited, cultural mastery, exploration radius, travel confidence
- Behavior: Map animates growth, mastery rings expand

### 5.4 Future Intelligence Cards
- Elements: Next destinations, amplitude-matched regions, cultural modules, bundle recommendations
- Behavior: Predictive glow on matched destinations

## 6. UTILITY + MOTION COMPONENTS

### 6.1 Motion System
- Smooth transitions, amplitude pulses, cultural fades, route animations, glyph micro-gestures
