# Dashboard 8-Panel Grid Layout Rebuild — Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Rebuild the dashboard from the current "7 cards scattered around a globe" layout into the **8-panel grid** from reference image #14 — one panel per subsidiary (Travel, Shoes, Games, Kids, Innovation, E-Waste, Quantum) plus a Dashboard panel, each with a hero area, stat row, and thumbnails, unified black-and-gold.

**Architecture:** No Next.js source exists (confirmed — the `package.json` files on disk are for aura-*/vagary skills, not this dashboard). The dashboard is built React output on gh-pages. The 7 subsidiary cards are rendered by the built chunk `page-de25f2d82934b8a4.js` as `.hybrid-card` elements with **hardcoded inline `position:absolute; left/top %`** (a scattered ring: 20%/25%, 80%/25%, 50%/15%, 30%/50%, 70%/50%, …). The globe canvas draws behind them. The rebuild is done via **post-render CSS override injection** (the established pattern) that repositions the cards into a responsive grid, restyles each into a panel, and adds the hero/stat/thumbnail structure. The globe becomes a subtle background (or is hidden) rather than the layout anchor.

**Tech Stack:** CSS (grid + `!important` overrides on inline styles), the existing git-plumbing injectors, vanilla JS injection for panel content (stats/thumbnails), black-and-gold palette (`#d4af37` on near-black) + the diamond cursor already in place.

## Current state (verified read-only)

- 7 `.hybrid-card` elements, each `position:absolute; width:320; minHeight:96` with inline `left/top %` positions baked into `page-de25f2d82934b8a4.js`.
- Card data array (hardcoded in chunk): `{id, name, icon, color, href}` for the 7 subsidiaries. Colors are the OLD per-subsidiary hexes (the theme injector overrides `--accent` to gold at runtime, but the inline `color` in the array still drives some inline styles).
- Globe canvas (`kdc-globe-canvas`, `position:fixed; z-index:0`) + `.canvas-root`/`.content-overlay-layer` (z-index 1/5).
- Reference #14 wants **8 panels** (adds a "Dashboard" panel with sidebar/stats/chart) in a 4×2 grid, each with hero image, 3 stats, 3 thumbnails, KDCI logo corner.
- No source repo → cannot edit the React component directly; must override via injected CSS/JS after render (same approach as globe/dropdown/theme).

## Key constraint / risk

- The cards are React-rendered with **inline styles**. CSS `!important` overrides `left/top/width/position` reliably, but **cannot change the card's internal content structure** (the hero/stat/thumbnail markup is generated by React). So:
  - **Repositioning into a grid: fully doable** via CSS override.
  - **Adding hero images / stat rows / thumbnails INSIDE each card: NOT doable via CSS** — that content doesn't exist in the DOM. It requires either (a) injecting new DOM via JS after render, or (b) accepting a simpler grid of the existing cards (name + icon + link) styled as panels.
- **Decision needed (open question below):** full panel richness (hero/stats/thumbnails) needs JS DOM injection per card; a clean grid of restyled existing cards is CSS-only and lower-risk.

## Design decisions (proposed)

- **Layout:** responsive CSS grid, 4 columns × 2 rows on desktop (8 cells), collapsing to 2-col / 1-col on smaller screens. Cell 1 = Dashboard panel, cells 2-8 = the 7 subsidiaries in reference order (Travel, Shoes, Games, Kids, Innovation, E-Waste, Quantum).
- **Globe:** demote to a faint background (reduce opacity / keep behind grid) OR hide it — the grid becomes the hero. Recommend: keep globe at very low opacity behind the grid for brand continuity, OR hide if it clutters. (Open question.)
- **Panel styling:** black-and-gold, glass cards, gold accents, diamond cursor (already global). Each panel: title, icon, link to its subsidiary.
- **Richness:** Option A (CSS-only grid of restyled cards) vs Option B (JS-injected hero/stat/thumbnail panels). See open question.

# PHASE A — Grid repositioning (CSS override, low risk)

## Task A1: Override card positioning into a responsive grid

**Objective:** Reposition the 7 `.hybrid-card` elements from the scattered absolute ring into a clean grid via injected CSS `!important`.

**Files:**
- Create: `C:\Users\young\agents\KingDesignCollectiveinc\_dashboard_grid.py` (new injector)
- Deploy target: `gh-pages:index.html` (dashboard)

**Steps:**
1. Inject a `<style id="kdc-dash-grid">` before `</body>` that overrides:
   - `.content-overlay-layer { position:static; display:grid; grid-template-columns:repeat(4,1fr); gap:18px; padding:24px; align-items:start; }` (was `position:absolute; inset:0; pointer-events:none` — need `pointer-events:auto` on cards).
   - `.hybrid-card { position:relative !important; left:auto !important; top:auto !important; width:100% !important; minHeight:180px !important; transform:none !important; }` (kills the inline absolute ring).
   - Responsive: `@media (max-width:1100px){grid-template-columns:repeat(2,1fr)} @media (max-width:640px){grid-template-columns:1fr}`.
2. Id-guard `kdc-dash-grid`; strip prior before inject; self-heal (cards are React-rendered, but CSS applies regardless of render timing — no MutationObserver needed for pure CSS).
3. Run injector via git plumbing (copy `_globe_network.py`'s plumbing tail). `node --check` any JS (none needed for CSS-only).
4. Trigger Pages rebuild. Verify live: browser-load dashboard, confirm cards form a grid (not a ring), globe behind, nothing overlaps, links work.
