# TREASURY SETUP INSTRUCTIONS

## SCOPE
This is the dispatch procedure for opening and seeding each subsidiary treasury.

## GLOBAL RULES
- Hub account: Umbrella Enterprise
- Subsidiary accounts: segregation required
- Currency default: USD unless jurisdiction requires otherwise
- Backup approver: CEO / Finance lead

## SETUP SEQUENCE
1. Detect chosen jurisdiction from `corporate_structure.json`
2. Verify KYC/AML requirements for that jurisdiction
3. Open business account for subsidiary legal name
4. Record account metadata in this directory
5. Coordinate initial capital transfer from parent hub account

## STATUS
Template only — no accounts opened.
