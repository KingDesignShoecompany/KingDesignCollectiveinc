# Travel Data Integrity + Card Link Wiring — Implementation Plan

> **For Hermes:** Implement task-by-task. User prefers direct execution over
> subagents (per user profile) — do NOT use delegate_task.

**Goal:** Fix the two highest-visibility data-quality defects in the deployed
travel platform: (1) the country snapshot's region taxonomy is a mix of
slugified internal labels and human-readable WorldBank labels, producing 23
region filter buttons including duplicates like `mena`/`MENA` and
`south_asia_1`/`South Asia`; (2) the shoe "Checkout" card links to the catalog
instead of a real cart, and no page ever displays the cart that
`product-detail` writes to.

**Architecture:** Pure data-layer normalization. The snapshot is a committed
static JSON file (`public/data/countries.json`) fetched by
`src/data/countries.ts`; the country list page derives its region filter
buttons directly from the `region` field. Normalizing regions to a single
canonical human-readable set at the *snapshot* layer fixes the UI, the map
legend counts, and the WorldMap panel without touching any component. The cart
gets a real page + a shell-level badge so `useCart` state is finally visible.

**Tech Stack:** Next.js 15 static export, React 18, TypeScript, plain CSS
tokens, Vitest (local guardrail, not in CI), Vagary API (`localhost:8080`).

```ts
// Canonical region taxonomy. The committed snapshot mixes WorldBank labels
// ("Europe & Central Asia") with slugified internal labels ("mena",
// "south_asia_1", "east_asia_block2"); normalizeRegion collapses both onto one
// human-readable set so the country list shows 8 filter buckets, not 23.
export const REGION_ORDER = [
  'East Asia',
  'Southeast Asia',
  'South Asia',
  'Middle East',
  'Europe',
  'Africa',
  'North America',
  'South America',
  'Oceania',
  'Unclassified',
] as const;

const REGION_MAP: Record<string, string> = {
  // WorldBank human-readable labels
  'europe & central asia': 'Europe',
  'latin america & caribbean': 'South America',
  'sub-saharan africa': 'Africa',
  'east asia & pacific': 'East Asia',
  'middle east, north africa, afghanistan & pakistan': 'Middle East',
  'north america': 'North America',
  'south asia': 'South Asia',
  // Slugified internal labels
  mena: 'Middle East',
  middle_east: 'Middle East',
  ssa: 'Africa',
  africa: 'Africa',
  north_america: 'North America',
  oceania: 'Oceania',
  south_america: 'South America',
  americas: 'South America',
  sea2: 'Southeast Asia',
  east_asia: 'East Asia',
  east_asia_block2: 'East Asia',
  europe: 'Europe',
  central_asia: 'South Asia',
  south_asia_1: 'South Asia',
  polar_micro: 'Unclassified',
  unclassified: 'Unclassified',
};

export function normalizeRegion(raw: unknown): string {
  const key = String(raw ?? '').trim().toLowerCase();
  if (!key) return 'Unclassified';
  return REGION_MAP[key] ?? 'Unclassified';
}
```

Note: `central_asia` deliberately maps to `South Asia` — Central Asian states
(Kazakhstan, Uzbekistan, Kyrgyzstan, Tajikistan, Turkmenistan) are grouped with
South Asia in the platform's existing taxonomy; if the user prefers a separate
`Central Asia` bucket, add it to `REGION_ORDER` and remap (see open question 1).

**Step 1: Write the page (no test — UI shell; covered by build + manual check)**

```tsx
'use client';

import Link from 'next/link';
import PageFrame from '../../components/PageFrame';
import HeroBanner from '../../components/HeroBanner';
import { useCart } from '../../hooks/useCart';
import { PRODUCTS, type Product } from '../../data/shoes';

export default function CartPage() {
  const { items, clear, count } = useCart();
  const byId = new Map<string, Product>(PRODUCTS.map((p) => [p.id, p]));
  const total = items.reduce(
    (sum, i) => sum + (byId.get(i.sku)?.price ?? 0) * i.qty,
    0
  );

  return (
    <>
      <HeroBanner kind="shoe" title="Cart" subtitle="Demo cart — review and check out" badge={`${count} item${count === 1 ? '' : 's'}`} />
      <PageFrame title="Your Cart" subtitle="Demo cart — no real payment gateway">
        {items.length === 0 ? (
          <div className="paywall">
            <div className="lock-ico">🛒</div>
            <h3>Your cart is empty</h3>
            <p>Browse the catalog and add a silhouette to get started.</p>
            <Link href="/products/" className="btn-gold">Browse catalog</Link>
          </div>
        ) : (
          <>
            <div className="cart-list">
              {items.map((i) => {
                const p = byId.get(i.sku);
                return (
                  <div key={`${i.sku}-${i.size}`} className="cart-row">
                    <div className="cart-name">{p?.name ?? i.sku}</div>
                    <div className="cart-meta">Size {i.size} · Qty {i.qty}</div>
                    <div className="cart-price">${((p?.price ?? 0) * i.qty).toFixed(2)}</div>
                  </div>
                );
              })}
            </div>
            <div className="cart-total">
              <span>Subtotal</span>
              <strong>${total.toFixed(2)}</strong>
            </div>
            <div className="filter-row" style={{ marginTop: 16 }}>
              <button className="btn-gold" disabled>Checkout — demo only</button>
              <button className="btn-outline" onClick={clear}>Clear cart</button>
            </div>
            <p style={{ color: 'var(--muted)', fontSize: '.8rem', marginTop: 12 }}>
              This is a demo cart stored locally in your browser. No payment is processed.
            </p>
          </>
        )}
        <div style={{ textAlign: 'center', marginTop: 20 }}>
          <Link href="/products/" className="btn-outline">← Back to catalog</Link>
        </div>
      </PageFrame>
    </>
  );
}
```

Note the `<Link href="/products/">` — bare path, `<Link>` auto-applies basePath.
Do NOT write `/KingDesignCollectiveinc/products/` inside a `<Link>`.
