# Legacy Archive

Everything in this directory is **old code kept for reference only**. It is not
used by the live platform and is safe to read but must not be run or edited.

## Source of truth

The **React app in `kdc-next/`** (Next.js 15 static export) is now the single
source of truth for all public-facing pages. It is deployed automatically to
GitHub Pages (`gh-pages` branch, force-orphan) on every push to `main` via
`.github/workflows/deploy-kdc-app.yml`.

## Contents

### `injectors/`

Python scripts that used to **post-process the legacy static HTML site** by
injecting navigation, themes, logos, and a JS world map directly into built HTML
files. They operated on `_next/` output and `*.html` files in the repo root.

| File | What it did |
|---|---|
| `_dashboard_grid.py` | Rebuilt the dashboard into an 8-panel black-and-gold grid |
| `_deploy_subpages.py` | Deployed legacy static sub-pages to gh-pages |
| `_fix_links.py` | Fixed double-prefixed hrefs in injected HTML |
| `_gen_logos.py` | Generated subsidiary logo assets |
| `_globe_network.py` | Generated globe/network hero art |
| `_inject_logos.py` | Injected logos into pages |
| `_nav_dropdown.py` | Injected the dropdown navigation |
| `_theme_subsidiaries.py` | Applied per-subsidiary accent themes |
| `_update_subpages.py` | Updated migrated sub-pages |
| `_vagary_map.py` | Injected the JS world map (equirectangular dot map) |

**Replaced by:** React components in `kdc-next/src/` —
`WorldMap.tsx` (map), `AppShell.tsx` (nav), `HeroBanner.tsx` (banners),
`theme.ts` (tokens). The map geometry from `_vagary_map.py`
(equirectangular projection) was reimplemented natively in `WorldMap.tsx`.

## Data snapshot re-export

The committed offline snapshot `kdc-next/public/data/countries.json` was
generated by joining the Vagary API `/countries` output with the local WorldBank
country file (ISO3 join, single pass — never 250+ sequential HTTP calls, which
time out). To regenerate after the API data changes:

1. `curl http://localhost:8080/countries` → live list (no lat/lon)
2. Join lat/lon by ISO3 against `vagary_index/references/worldbank_countries.json`
3. Filter null `code`/`name` rows; normalize `region` nulls to `Unclassified`
4. Write to `kdc-next/public/data/countries.json` with a `coverage` field
